# Roadmap

This roadmap describes research order, not promised dates.

## Phase 1 — architectural baseline

- Publish the top-level domains and contracts.
- Define Individual continuity and lifecycle boundaries.
- Separate Architecture, Research Goal, Planned, and Implemented status.

## Phase 2 — regulation and embodiment foundations

- Define artificial physiology state ownership.
- Prototype energy, interoception, homeostasis, and safety state.
- Define a body abstraction that can target simulation and physical embodiments.
- Establish action feedback and learned body-model measurements.

## Phase 3 — developmental learning core

- Build a minimal environment with unfamiliar objects.
- Add perception, attention, memory formation, prediction error, exploration, imitation, forgetting, and consolidation.
- Run the First Concept Formation Experiment.

## Phase 4 — increasingly rich models

- Body model and object permanence.
- Affordance learning and prediction.
- Concept system and grounded language learning.
- World model, self model, social learning, and skill learning.

## Phase 5 — continuity and provider independence

- Snapshot and migration protocols.
- Model-provider replacement experiments.
- Evidence-based continuity criteria across software, model, and body changes.
