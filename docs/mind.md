# Mind

Mind is the cognitive domain. Long-term capabilities may include perception, attention, working memory, long-term memory, learning, prediction, prediction error, concepts, world models, self models, social models, emotion, motivation, executive control, language learning, skills, planning, imitation, curiosity, exploration, forgetting, and consolidation.

These names are not permission to wrap one prompt in many labels. Each capability should become an observable state, an owned data structure, an interface, a learning mechanism, and a testable behavior.
