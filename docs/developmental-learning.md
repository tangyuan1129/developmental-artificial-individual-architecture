# Developmental learning

```text
External World → Body → Perception → Attention → Internal State
→ Memory → Learning → Prediction → Concept Formation → World Model
→ Self Model → Executive Control → Action → Consequence ↺
```

Knowledge, language, models, relationships, skills, preferences, and personality should be treated as developmental outcomes wherever feasible, not as a prewritten character card.

Birth permits minimal structural priors and minimal semantic priors needed for learning: perception mechanisms, attention, memory formation, pattern discovery, association, prediction, prediction error, reward learning, curiosity, exploration, imitation, forgetting, consolidation, basic drives, body sensation, homeostasis, protection, and learning rules. It should not directly provide mature object meanings, world knowledge, personal experience, relationships, social rules, mature self-concept, learned skills, or fixed preferences.
