# LLM position

LLM is an optional reasoning provider behind an interface:

```text
Artificial Individual → Cognitive Architecture → Reasoning Provider Interface
                                      ├── LLM
                                      ├── Symbolic provider
                                      └── Future provider
```

The architecture must preserve identity, memories, concepts, skills, development history, relationships, internal state, learned body model, and self model when a provider changes or is absent. Provider replacement is a future continuity experiment, not a claim already validated.
