# Lifecycle and birth

```text
DEVELOPMENT → INTERNAL_TEST → EMBODIMENT_TEST → PRE_BIRTH → BORN
```

## Development

Software development may generate debug conversations, simulated knowledge, test emotions, calibration data, temporary memory, and experimental relationships. None is official life experience by default.

## Internal test

The system validates memory, learning, physiology, kernel, lifecycle, executive control, data ownership, and event behavior.

## Embodiment test

The system validates body APIs, sensors, motors, interoception, proprioception, action feedback, and safety behavior.

## Pre-birth

The formal data space is checked, test data is isolated, identity and lifecycle fields are verified, birth is auditable, and snapshot/rollback procedures are tested.

## Born

Only `BORN` creates `individual_id`, `birth_time`, `birth_event`, the official life timeline, official memory history, official relationship history, and the official developmental record. Birth is a data and identity boundary, not a UI animation.
