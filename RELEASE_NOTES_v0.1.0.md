# v0.1.0 — Architecture Specification

This is the first public design release of the Developmental Artificial Individual Architecture.

It establishes the public architectural baseline for:

- project vision;
- Artificial Individual definition;
- top-level architecture;
- lifecycle and birth boundary;
- Artificial Physiology direction;
- Body abstraction;
- developmental learning principles;
- contract-first engineering principles;
- initial research roadmap.

This is a specification release, not a claim that the complete implementation already exists.
